### Security & System Tools
*   **[Git Manager](https://github.com/JCarvell67/git-manager)** — Dark, minimalist desktop app built with Python and Tkinter for managing repos, handling commits/branches, and switching profiles on the fly.
*   **[Port Scanner](https://github.com/JCarvell67/port-scanner)** — Multi-threaded GUI network scanner built in Python using standard libraries. Scans open ports, identifies services, and exports results to JSON, CSV, or TXT.

### AI & Computer Vision
*   **[Neural Snake](https://github.com/JCarvell67/snake-ai)** — Snake game where a neural network learns via a genetic algorithm. Includes live visual training, real-time telemetry diagrams, and headless terminal mode.
*   **[NeuralNav: AI City Pathfinder](https://github.com/JCarvell67/neuralnav)** — Browser-based pathfinding tool that connects to OpenStreetMap and OSRM to simulate AI node search over real-world road networks.

### Data & Visualization
